# Умный помощник для конспектирования встреч

Backend-сервис на Go: принимает аудиозапись или текстовый файл встречи, асинхронно
получает расшифровку и краткую выжимку через заменяемые внешние клиенты, хранит
результат в PostgreSQL, ищет по сохранённым материалам и отвечает на вопросы по ним.

Пользовательский интерфейс: **CLI на cobra**. Внешние сервисы распознавания речи и LLM
описаны интерфейсами; в комплекте идут рабочие тестовые реализации, а реальный клиент
подключается сменой одного значения в конфигурации.

## Быстрый старт

```bash
cp .env.example .env
docker compose up -d
go run ./cmd/meetnotes migrate up
```

Дальше нужны два терминала: CLI и фоновый обработчик.

```bash
# терминал 1: фоновая обработка
go run ./cmd/meetnotes worker

# терминал 2: работа пользователя
go run ./cmd/meetnotes --user maksim start
go run ./cmd/meetnotes --user maksim load ./testdata/meeting_ru.txt
go run ./cmd/meetnotes --user maksim list
go run ./cmd/meetnotes --user maksim status <meeting-id>
go run ./cmd/meetnotes --user maksim get <meeting-id>
go run ./cmd/meetnotes --user maksim find "нагрузочное тестирование"
go run ./cmd/meetnotes --user maksim chat --meeting <meeting-id> "какие договорённости?"
```

Пользователь задаётся флагом `--user` или переменной `MEETNOTES_USER` и создаётся
автоматически при первом обращении.

## Команды

| Команда | Назначение |
|---|---|
| `start` | Регистрация пользователя (остальные команды делают это автоматически) |
| `load <path>` | Загрузить файл встречи, создать встречу и задачу обработки |
| `list` | Список своих встреч: идентификатор, дата, статус, выжимка |
| `status <id>` | Статус обработки, даты, число попыток, текст ошибки, история переходов |
| `get <id>` | Транскрипция и выжимка встречи; `--out file` сохраняет расшифровку в файл |
| `find <keyword>` | Полнотекстовый поиск по своим встречам с подсветкой фрагмента |
| `chat <text>` | Вопрос к LLM по сохранённым материалам; `--meeting <id>` задаёт контекст |
| `retry <id>` | Вернуть в очередь задачу, завершившуюся ошибкой |
| `delete <id>` | Удалить встречу и все связанные данные |
| `stats` | Сводка: число задач по статусам, среднее время обработки, число ошибок |
| `history` | История вопросов и ответов |
| `worker` | Запустить фоновый обработчик очереди |
| `migrate up\|down\|status` | Миграции базы данных |

Общие флаги: `--user`, `--env`, `--log-level`, `--log-format`, `--json`, `--timeout`.
Флаг `--json` выводит результат машинно-читаемо; логи всегда идут в stderr, результат — в stdout.

Коды возврата: `0` — успех, `2` — неверный ввод, `3` — не найдено,
`4` — операция недопустима в текущем состоянии, `1` — внутренняя ошибка.
